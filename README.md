# 全ポケモン言えるかな（協力版）

[全ポケモン言えるかな？](https://all-pokemon-ierukana.com/) 風の暗記クイズ Web アプリ。
思い出したポケモンの名前をひたすら入力して、全 1025 匹の図鑑を埋めていく。

- **協力プレイ前提**: 進捗は Google スプレッドシートに保存され、全員で 1 つの図鑑を分担して埋められる（1人で遊んでもOK）
- **セーブ不要**: 回答した瞬間にシートへ記録されるので、いつ閉じても続きから遊べる
- **ビルド不要の静的サイト**: HTML/CSS/JS のみ。S3 や GitHub Pages に置くだけで動く

## 遊び方

1. ページを開くとニックネームを聞かれるので入力する
2. 入力欄にポケモンの名前を入れて Enter（ひらがな・カタカナどちらでもOK）
3. 正解すると図鑑のマスが開き、誰が答えたかが記録される
4. 他の人の回答は、自分が回答したとき・「更新」ボタンを押したとき・ページを開いたときに取り込まれる
5. 降参したいときは「残りを表示」にチェック（表示だけで、進捗には影響しない）
6. 全員でやり直すときは 設定 → 「みんなの進捗を最初からやり直す」（過去の記録はシート側に `log_日時` として残る）

表記ゆれはある程度吸収する（例: `ぽりごんぜっと` → ポリゴンＺ、`にどらんおす` → ニドラン♂、`たいぷぬる` → タイプ：ヌル）。

## すぐ試す（お試しモード）

`index.html` をブラウザで開くだけで動く。ローカルサーバーを立てる場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

共有シート未設定のあいだは「お試しモード」となり、進捗はその端末のブラウザ内（localStorage）にのみ保存される。

## 共有シート（協力モード）のセットアップ

DB として Google スプレッドシート + Google Apps Script (GAS) を使う。約5分。

1. [Google スプレッドシート](https://docs.google.com/spreadsheets/) を新規作成する（名前は自由）
2. メニューの **拡張機能 > Apps Script** を開く
3. エディタの内容をすべて消し、このリポジトリの `gas/Code.gs` の中身を貼り付けて保存する
4. 右上の **デプロイ > 新しいデプロイ** を開く
   - 種類の選択（歯車アイコン）: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」を押し、承認を求められたら自分のアカウントで許可する
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーする

コピーした URL をアプリに設定する方法は 2 通り:

- **配布用（推奨）**: `js/config.js` の `GAS_URL` に貼ってからファイル一式をホスティングに置く。開いた人全員が自動で同じシートに接続される
- **個人設定**: アプリの「設定」画面で URL を貼る（その端末にのみ保存される）

### 注意

- この URL を知っている人は**誰でも読み書きできる**。遊ぶメンバーだけに共有し、公開リポジトリに `config.js` ごと置く場合はその点を理解しておくこと
- `Code.gs` を修正した場合は **デプロイ > デプロイを管理 > 編集（鉛筆）> 新バージョン** で更新しないと反映されない

## ホスティング（S3 / GitHub Pages など）

ビルドは不要。以下のファイル/フォルダをそのまま静的ホスティングにアップロードするだけ:

```
index.html
css/
js/        （config.js に GAS_URL を設定しておく）
```

`scripts/` と `gas/` は配信不要（開発・セットアップ用）。

## 開発メモ

- ポケモンデータ（`js/pokedex.js`）は [PokeAPI](https://pokeapi.co/) のデータから生成している。新世代の追加などで再生成する場合:

  ```sh
  node scripts/generate-pokedex.mjs
  ```

- 画像は PokeAPI のスプライトを直接参照している（正解したマスのみ遅延読み込み）

## ファイル構成

```
index.html                     画面
css/style.css                  スタイル
js/config.js                   デプロイ設定（GAS_URL）
js/pokedex.js                  ポケモンデータ（自動生成）
js/normalize.js                名前の正規化・判定
js/api.js                      共有シートとの同期（+お試しモード実装）
js/app.js                      画面の描画とイベント
gas/Code.gs                    Apps Script（スプレッドシート側 API）
scripts/generate-pokedex.mjs   ポケモンデータ生成スクリプト（開発用）
```
