# ポケモンいえるかな

[全ポケモン言えるかな？](https://all-pokemon-ierukana.com/) 風の暗記クイズ Web アプリ。
思い出したポケモンの名前をひたすら入力して、全 1025 匹の図鑑を埋めていく。

- **協力プレイ前提**: 進捗は Google スプレッドシートに保存され、全員で 1 つの図鑑を分担して埋められる（1人で遊んでもOK）
- **部屋**: 4 桁の部屋 ID ごとに図鑑を持てる。ID を共有した人同士で 1 つの図鑑を埋める。最初は全員が「みんなの部屋」（共有の図鑑）に入室済み
- **セーブ不要**: 回答した瞬間にシートへ記録されるので、いつ閉じても続きから遊べる
- **ビルド不要の静的サイト**: HTML/CSS/JS のみ。S3 や GitHub Pages に置くだけで動く

## 遊び方

1. ページを開くとニックネームを聞かれるので入力する
2. 最初は全員が「みんなの部屋」にいる。友達とだけ遊ぶなら 設定 → 部屋 → 「新しい部屋を作る」で 4 桁の部屋 ID を発行し、相手は同じ画面で ID を入力して「入室」する。今いる部屋はヘッダーの部屋名で分かる（タップで設定が開く）
3. 入力欄にポケモンの名前を入れて Enter（ひらがな・カタカナどちらでもOK）
4. 正解すると図鑑のマスが開き、誰が答えたかが記録される
5. 他の人の回答は、自分が回答したとき・「更新」ボタンを押したとき・ページを開いたときに取り込まれる（開いた直後は前回見た時点の状態が先に表示され、数秒で最新に更新される）
6. 世代の見出しをクリックすると折りたたみ／展開できる（開閉状態は端末ごとに記憶される）
7. 設定 → 「タイプヒントを表示」を ON にすると、未回答のマスにそのポケモンのタイプが表示される（端末ごとの設定）
8. 入室したことのある部屋は 設定 → 部屋 の一覧（回答者名つき）からタップで切り替えられる。次回以降は最後に遊んだ部屋が自動で開く（一覧・最後の部屋は端末ごとの記憶。一覧から部屋を消す機能は無い）
9. 部屋の全員でやり直すときは 設定 → 「この部屋の進捗を最初からやり直す」（過去の記録はシート側に `log_部屋ID_日時` として残る）

表記ゆれはある程度吸収する（例: `ぽりごんぜっと` → ポリゴンＺ、`にどらんおす` → ニドラン♂、`たいぷぬる` → タイプ：ヌル）。

## ローカルで動かす

`js/config.js` に共有シートの URL（下記セットアップ参照）が設定されていれば、`index.html` をブラウザで開くだけで動く。ローカルサーバーを立てる場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

URL が未設定の場合は動作せず、画面にエラーが表示される。

## 共有シート（協力モード）のセットアップ

DB として Google スプレッドシート + Google Apps Script (GAS) を使う。約5分。

1. [Google スプレッドシート](https://docs.google.com/spreadsheets/) を新規作成する（名前は自由）
2. メニューの **拡張機能 > Apps Script** を開く
3. エディタの内容をすべて消し、このリポジトリの `gas/Code.gs` の中身を貼り付けて保存する
4. 右上の **デプロイ > 新しいデプロイ** を開く
   - 種類の選択（歯車アイコン）: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」を押し、承認を求められたら自分のアカウントで許可する
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーする

コピーした URL を `js/config.js` の `GAS_URL` に貼ってからファイル一式をホスティングに置くと、開いた人全員が自動で同じシートに接続される。

### 注意

- この URL を知っている人は**誰でも読み書きできる**。遊ぶメンバーだけに共有し、公開リポジトリに `config.js` ごと置く場合はその点を理解しておくこと
- `Code.gs` を修正した場合は **デプロイ > デプロイを管理 > 編集（鉛筆）> 新バージョン** で更新しないと反映されない（部屋機能の導入時も同様に再デプロイが必要）
- 部屋を作るとスプレッドシートに `room_1234` のようなシートが自動で増える。既存の `answers` シートは「みんなの部屋」（部屋 ID 0000）として使われる。部屋 ID は仕分け用で秘密ではない（4 桁なので推測できる。URL を知る人は誰でも読み書きできるという前提は変わらない）

## ホスティング（S3 / GitHub Pages など）

ビルドは不要。以下のファイル/フォルダをそのまま静的ホスティングにアップロードするだけ:

```
index.html
css/
js/        （config.js に GAS_URL を設定しておく）
```

`scripts/` と `gas/` は配信不要（開発・セットアップ用）。

## 開発メモ

- ポケモンデータ（`js/pokedex.js`）は [PokeAPI](https://pokeapi.co/) のデータから生成している。新世代の追加などで再生成する場合:

  ```sh
  node scripts/generate-pokedex.mjs
  ```

- 画像は PokeAPI のスプライトを直接参照している（正解したマスのみ遅延読み込み）

## ファイル構成

```
index.html                     画面
css/style.css                  スタイル
js/config.js                   デプロイ設定（GAS_URL）
js/pokedex.js                  ポケモンデータ（名前・世代・タイプ、自動生成）
js/normalize.js                名前の正規化・判定
js/api.js                      共有シートとの同期（部屋単位、送信キュー付き）
js/app.js                      画面の描画とイベント
gas/Code.gs                    Apps Script（スプレッドシート側 API。部屋 = シート）
scripts/generate-pokedex.mjs   ポケモンデータ生成スクリプト（開発用）
```
